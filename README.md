## Status of this repository

The original React + Vite source for this site was developed locally on
2026-05-07 and deployed to Vercel, but the source tree is no longer present
on disk.

What is committed here is the **recovered deployment artifact** pulled from
the live Vercel deployment: the built `index.html`, the minified JS/CSS
bundles, and the public image assets under `flexy/`. The original component
source (TSX), `package.json`, Vite config, and styling source are **not**
recoverable from the deployment.

No client contact details are published in this repository.
